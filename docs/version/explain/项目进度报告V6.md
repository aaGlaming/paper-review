### 2.1 接口层的已知边界

- **pdf 不在线上解析**：上传只收 `.md` 与 `.docx`，pdf 在扩展名校验处返回 415。真实论文是扫描件，OCR 已离线做过一次，`data/samples/*.md` 就是那份产物。
- **上传路径不能用 `/reviews/upload`**：会被 `GET /reviews/{review_id}` 吞掉并返回 405，故用独立前缀 `POST /api/uploads`。
- **大屏聚合有 60 s TTL**，响应带 `cached` 字段；数值与只读 SQL 的一致性由 `report-V4.md` §2 抽查。

## 三、核心流程与完成度

### 3.1 主路径

```
登录（scrypt + 自签 token）
  → 选赛题（无已发布量规则禁止提交，返回 422）
  → 上传 md/docx 或选样例 → 章节树（ATX 标题切分）
  → 确认 → resume（同步，模型路径实测中位 31.7 s，等待秒数可见）
  → 四节点图 parse → confirm → retrieve → score
  → 报告（四档 band、原句逐字校验、修改清单、上游 ID）
  → 大屏 / 记录总览 / AI 问询（定点问法走 MySQL，通用问法走向量）
```
