## 2. 设计说明（遵循 sketch.md §3 手绘约定与既有 `sketch.css` 三条绘制约定）

- 线条 `stroke="currentColor"`：图标颜色随昼夜主题自动走墨色，无需两套文件。
- `stroke-width` 1.0–1.7，`linecap/linejoin="round"`，`fill="none"`。
- 路径一律微弯不取直：太阳外圈为不规则椭圆、光芒为短波浪线；月亮为不对称弯月。
- 重点形状描两遍：太阳外圈第二遍 `opacity 0.5` 略偏移；月亮内圈复线 `opacity 0.5`。
- 太阳：`viewBox 48×48`，中心圈 + 八道光芒（上 / 下 / 左 / 右 / 四角各一道）。
- 月亮：`viewBox 48×48`，弯月主体 + 内圈复线 + 两颗小星（星为手绘小圈，非 emoji）。
- 无十六进制色值、无渐变、无滤镜、无动画；`aria-hidden="true"`，按钮以 `alt`（太阳 / 月亮）与 `aria-label`（切换到黑夜 / 白天模式）表达语义。
