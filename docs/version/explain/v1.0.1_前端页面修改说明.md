## 1. 结论

- 五个页面已是手稿风（P8 交付的纸底 + 手绘边框 + 胶带 + 圈注 + 衬线引文保持不动），本版在其上叠加**昼夜两套主题**。

## 3. 可复用 / 需重设计盘点

14 个旧 SVG（箭头 / 圆圈 / 下划线 / 卡片边框 / 铅笔 / 胶带 / 放大镜 / 文档树 / 清单 / 图表 / 引号 / 纸纹 / 流程点）**全部可复用**：均为 `stroke="currentColor"` 手绘约定，随主题自动变色，无需重画。

需重设计：太阳 / 月亮切换图标（旧库无）——已按 sketch 约定（线条 1.0–1.7、round 端点、微弯不取直、重点形状描两遍）新画，见本文 §2 与 `v1.0.2_前端页面修改说明.md`。
