### 1.2 本版修掉的三个真实问题

**① 向量库原生崩溃（最严重）**

- 现象：全量 pytest 跑到访问 Chroma 的用例就整进程消失（`-1073741819`），真机问答与摘要同样中断，E2E 从 40/8 掉到 24/24。
- 取证顺序：只读直连 `chroma.sqlite3` → `embeddings` 16347 行、segments 完整（**数据没丢**）→ 停后端 probe 崩、开后端 probe 也崩（**排除单纯并发**）→ 新建空目录 probe 正常（**新建能活、旧库不能**）。
- 处置：旧目录完整保留为 `chroma_data.broken-20261020-055434`（未删）；从 5,514 个论文父块重建 20,807 个子块，再写入 510 条记录子块，重建后 count 21,317；`review` / `review_dimension` / `paper_parent` 三表一行未动。
- 根因侧修复：`set_client_for_tests` / `reset_client_for_tests` + conftest 全局 autouse `isolate_chroma`（每条测试用临时 PersistentClient）。修复后**后端运行中连跑两遍 356 passed，生产库 embeddings 前后一致**。

**② 详情抽屉缺正文，原句定位无法实现**

`GET /api/reviews/{id}` 的落档分支只返回档案，不含 `sections`；而定位函数需要拼接后的全文。补法是让落档分支从 `review_session` 带上 `sections`（无快照给空数组）——**没有新开接口**，因为同一份数据两套接口，改一处必忘另一处。

**③ 登录页背景 2.35 MB**

Pillow 压到 1600×900 WebP，**81 KB（3.3%）**，PSNR 39.0 dB。坑：本机 `which convert` 命中的是 `C:\Windows\system32\convert.exe`（NTFS 工具，不是 ImageMagick）。

### 2.1 接口层的已知边界

1. **401 / 403 / 404 三码分工是刻意的**：没登录 401；能力类接口（`/api/users`、`/api/chat/*`）无权限 403；查别人的私有资源（详情、会话）404——403 会暴露「这个 id 存在」。
2. **无主记录**（`review.user_id IS NULL`）仅教师可读，学生 404。当前 109 条里绝大多数仍是无主（首期遗留）。
3. **`/api/chat/*` 全部挂 `chat:use`**，学生调一律 403；会话归属只认 `user_id`，不接受请求体里的身份。
4. **`/metrics` 不做鉴权**（按 Prometheus 惯例），但它只输出计数与耗时，不含任何正文或凭据。

## 五、遗留问题清单

### 5.1 阻塞「P19 全部通过」的（1 项）

**问询的检索精度**：问「这条记录的假设维档位是什么？」时，答案引用了同赛题的其他记录而非被问的那条。链路本身正常（200、带 refs、可溯源），但「问哪条就答哪条」没做到。这条不解决，前端问询页做完也点不到对的记录。

### 5.2 不影响主流程的（4 项）

1. **摘要数字覆盖不完整**：某次摘要里四个维度分项合计 83、统计总数 88，差额 5 未解释；
2. **E2E 8 条既有红灯**：`consistency` / `parse`×2 / `scoring` / `sketch-fix`×2 / `suggestions` / `visual`，全部卡在「确认卡 5 秒超时」这一类链路，与 `v3.2.3` 一致；
3. **`logs/agent/` 无写入者**：Agent 轨迹以 `agent_step` 表为唯一口径，目录预留；
4. **3 个历史段目录未清理**：`chroma_data.broken-*` 内 3 个不被当前 segments 引用的 UUID 子目录。

### 5.3 待决策（2 项）

1. **档位两种写法**：`证据不足` 81 条、`不足` 18 条。聚合层已用 `INSUFFICIENT_BANDS` 归一兼容；**是否清洗数据**需要单独立项——改已落档的 band 等于篡改历史证据。
2. **无主记录的产品口径**：109 条里绝大多数 `user_id IS NULL`。现在「教师可见、学生 404」是技术处理，产品上要不要标注「首期遗留」、要不要批量认领，留给 P18 之后的界面决策。

### 5.4 已被真实数据暴露、已修复的（3 项）

向量库原生崩溃、详情抽屉缺正文、登录页背景 2.35 MB —— 见 §1.2。
