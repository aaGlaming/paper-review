零、动手前自检（三条）

一、实现重排（backend/app/retrieve/）
1. 重排签名固定：输入是**查询**和**已经过滤后的候选**，输出是**这些候选的新顺序**。
   硬约束：输出集合必须与输入集合完全相同——**不得加入任何新文档，也不得把被过滤掉的段加回来**。传入候选之外的 id 必须抛错。
2. 三路材料分别过滤召回后合并，顺序固定，不得调换：
   a. 三路分别是：档位说明（band_text）、论文子块（paper_child）、扣分点（pitfall）；
   b. **三路各自先按 contest_id、rubric_id、section_type 过滤并召回**；
   c. **合并三路候选并去重**（同一个 parent_id 只留一份，命中它的 chunk_ids 合并保留）；
   d. 对合并后的候选做**一次**重排（只改顺序）；
   e. **截断到最多 4 段**。
   ⚠️ 是"合并后总共 4 段"，**不是每路各 4 段**。三路各送 4 段会变成 12 段，直接违反验收。
3. 两轮检索，次数必须精确：
   - 第一轮有结果 → **不进行第二轮**；
   - 第一轮为空 → 允许改写查询再查一轮；
   - 第二轮仍为空 → 该维度状态为「证据不足」，检索函数调用次数**恰为 2**，**不得出现第三次**。
4. 「证据不足」由**检索结果**触发，不得由模型临时决定跳过检索。

1. 在 confirm 之后、score 之前插入逐维检索节点，节点顺序为 parse → confirm → retrieve → score → END。
   score **仍然是占位节点**，只累加 score_node_calls，本版不改它的性质。
2. 按量规维度逐维检索：每个 dimension_code 各检索一次，结果写进状态，至少含该维的父块列表与状态（命中 / 证据不足）。
3. 本版图内**不得出现任何模型调用**：不导入 backend/app/llm/client.py，不含 httpx / requests / urllib / aiohttp 字样。
4. 章节未确认时不进入 retrieve 节点——沿用 P1 已通过的确认闸门，不得放宽。

三、先写 backend/tests/retrieve/test_rerank_cap.py，再写实现
优先用内存假件（假向量存储 + 内存父块仓储 + 假重排客户端），不依赖 Docker、不访问网络、不下载嵌入模型。
至少 9 个测试函数：
1. 过滤后只剩 2 段时，倒序重排后的 id 集合仍是那 2 段（集合相等）。
2. 重排客户端试图加入候选之外的 id 时抛错。
3. 候选多于 4 段时，进入后续步骤的父块数为 4。
4. 三路各召回多条后，合并截断的**总数为 4**（不是 12，也不是 8）——用记录型假客户端断言每路收到的候选数。
5. 第一轮有结果时，检索函数调用次数为 1（没有第二轮）。
6. 第一轮为空、第二轮有结果时，调用次数为 2，且该维状态为命中。
7. 两轮都为空时，该维状态为「证据不足」，检索函数调用次数**恰为 2**。
8. 证据不足由检索结果触发：断言此时模型客户端一次都没被调用（用记录型假客户端或断言未导入）。

## 3. 为什么提示词要这么写（给你复核用）

| 约定 | 来源 | 为什么写进提示词 |
|---|---|---|
| 把 HTTP 出口冲突单列一条 | CLAUDE.md 硬约束 + 任务文档 §10 允许目录 | 任务文档 §10 要求"真实重排客户端只读 RERANK_BASE_URL 与 RERANK_MODEL"，但 CLAUDE.md 规定只有 `llm/client.py` 能发 HTTP——**规范自相矛盾**。不写死，AI 要么把 HTTP 写进 retrieve（破坏硬约束），要么卡住 |
| 默认做法选"不发请求" | 执行手册 §6.1 | 执行手册明说密钥缺失时"P4 过滤测试用 mock"。本版本就不需要真密钥，把真实 HTTP 留给允许改 `llm/client.py` 的版本，是最小代价解 |
| 强调"合并后总共 4 段，不是每路 4 段" | 任务文档 §10 任务 4 | 这是最容易理解错的一条。三路各 4 段 = 12 段，直接违反"每维最多 4 段"的验收，且**表面上还能跑通** |
| 第二轮次数写成"恰为 2" | 任务文档 §10 任务 3 | 只说"允许第二轮"不够——要钉死上界，否则可能写成循环重试，白烧调用 |
| 明说 graph 侧断言写在 `tests/retrieve` 里 | 任务文档 §10 允许目录 | 本版允许改的测试目录只有 `retrieve`，但改的模块含 `graph`。不说明，AI 会新建 `tests/graph/test_*.py` 而越界 |
| 本版不得调用 `chat()` | 任务文档 §11 分界 | 选档与加总是 P5。P4 若顺手把模型调用接进来，P5 的"原句必须是子串"就没有干净的验证边界 |
| 沿用 P1 的确认闸门 | 任务文档 §4.6 | 新增节点时最容易把 `interrupt()` 的暂停点挪走或绕过，导致"未确认也能评分"回归 |
| 本版不出新图 | 任务文档 §10 允许目录 | 五张图已全部交付，`docs/diagrams` 不在本版允许范围；重复出图只会制造无意义 diff |
