## 1. 本版概览

本版沿用“竞赛论文预审工作台”的校样纸和手绘批注视觉，把动态反馈限定在真实路由、用户操作和 API 请求状态上。工作台页面增加轻量切换与内容反馈；评测和大屏的数值变化使用接口返回值；聊天活动提示只在请求期间出现。支持系统减少动态效果设置，并以路由按需加载控制首屏资源。

| 主题 | 本版内容 |
|---|---|
| 页面视觉 | 统一纸张层级、边界、导航和主题令牌，更新相关组件与插画资源 |
| 认证体验 | 登录成功后提供可跳过的校样开场；保留安全重定向与键盘操作 |
| 状态反馈 | 路由、解析/评分/冲突/建议列表、记录筛选、问询和指标变化增加有界反馈 |
| 无障碍 | 尊重 `prefers-reduced-motion`；数值播报最终值；保留键盘焦点和状态可读性 |
| 性能 | 工作台路由按需加载，避免解析页和记录页首屏加载不需要的页面代码 |
| 设计交付 | 更新 `docs/design/sketch-svg/` 与 `docs/diagrams/` 中的视觉和架构说明 |

## 2. 主要变更

### 2.1 认证入口与登录后开场

- 登录和注册页按公开路由呈现，不在认证入口显示工作台导航。
- 登录成功后先播放一次校样展开 SVG；用户点击、按 Enter/Space 或 Escape 后才进入原本目标页。
- 对已有会话恢复、登出、认证失败不播放开场；注册成功登录后进入解析页。
- 尊重减少动态效果设置，提供语义化可跳过入口，避免开场期间目标页提前渲染。

### 2.2 全站状态反馈

- 路由切换采用短淡入和轻微归位；解析、评分、冲突与建议列表按稳定业务 key 过渡。
- 建议分组可展开/收起；记录筛选时保留当前行并显示真实请求状态。
- 问询的活动标记绑定真实请求生命周期，不模拟流式回答或虚构进度。
- 评测和数据大屏复用 `MotionNumber`，只在旧值到新值间短暂变化，最终值始终可读。
- 图表动画遵循 `prefers-reduced-motion`，空数据、低样本和错误状态沿用原有契约。

### 2.3 首屏资源与设计资产

- 页面路由组件改为按需加载，路由和业务逻辑保持不变。
- 重新整理 SVG 视觉资产与图表文件，补充架构、数据流、认证和交付门禁图。
- 当前首屏预算 E2E 记录：raw **1,029,932 bytes**，gzip **332,381 bytes**；相对原基线分别减少 87,250 和 23,499 bytes。大屏页面额外加载 1,565,380 raw / 509,410 gzip，页面模块可交互时间记录为 398.9 ms。
