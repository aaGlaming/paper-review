# paper-review 项目全面问题清单

> 用途：把这个项目从"我做过"补到"我能被追问三层"。共 **282 题**，只给问题不给答案。
> 与 `docs/interview/项目自测问题清单.md`（168 题，偏首期）的关系：那份覆盖到 Phase-1；本清单覆盖到当前版本，补上了 **Agent 层、鉴权与权限、记录级问询、大屏聚合、上传解析、可观测**六块。
> 顺序即学习顺序：**0 → A → C → F → H → J** 是可讲通的最小闭环；D / E / G / I / K / L 是细节加固；M～S 是面试官真正分高下的地方。
> 每题都能在本仓库的代码或文档里找到依据。答不上来的，先去读那一段，别背结论。

## 0. 开场自测（8 题，答不顺就别往后看）

- 0.1 不看稿讲 60 秒：谁的问题、你做了什么、结果是多少——能一次说顺吗？
- 0.2 一句话说清 RAG 在这个项目里解决什么，不许说"让回答更准确"。
- 0.3 一句话说清 Agent 在这里比固定流水线多了什么，不许说"更智能"。
- 0.4 系统最终交付给用户的是哪几样东西？哪一样最不可替代？
- 0.5 你会挑哪三个数字证明这个项目不是玩具？分别是什么口径？
- 0.6 你会主动承认哪个短板？为什么选择不修？
- 0.7 这个项目里你做过的最难的一个技术判断是什么？
- 0.8 面试官说"这不就是套壳大模型"，你的第一句话是什么？

## A. 定位、边界与业务价值（12 题｜基础）

- A1 这套系统服务的是哪一类人、替他们省掉哪一步劳动？没替代的那一步是什么？
- A2 "预审"和"评审/评奖"的界线在哪？为什么这条线必须画死？
- A3 需求明确禁止输出奖项、名次、获奖概率——如果需求不写，这功能会自然长出来吗？为什么危险？
- A4 用户凭什么相信系统这次的判断？产品上给了他哪些可核对的线索？
- A5 哪些论文根本不该进这个系统？你划的输入边界是什么？
- A6 同一篇论文两个人先后评，结果不一样，这算 bug 吗？你怎么向用户解释？
- A7 系统最容易误导使用者的地方在哪？你用什么机制防它？
- A8 如果只能保留一个功能，砍掉哪些还能成立？
- A9 这个项目和"AI 写作助手""论文查重"分别差在哪？
- A10 老师实际用起来会抱怨的第一件事是什么？你怎么接？
- A11 这套东西的价值能用一句话量化吗？不能量化的话，你怎么说服人它有用？
- A12 现在这套流程里，哪一步仍然是纯人工、且你认为永远该保留人工？

## B. 简历口径与"RAG + Agent"定位（14 题｜必答）

- B1 你简历上写 RAG+Agent——这两个词分别对应系统里的哪几段？说得出边界吗？
- B2 如果面试官只认"RAG = 检索增强生成"，你会把哪一段明确排除在 RAG 之外？为什么必须先排除？
- B3 检索出来的东西最终喂给了谁？喂给"一次性回答"和喂给"多轮工具调用"，差别在哪？
- B4 这个系统的 Agent 有记忆吗？记忆存在哪、跨不跨请求？
- B5 Agent 自己决定下一步做什么吗？哪些自由度是真的、哪些是被锁死的？
- B6 为什么不能让 Agent 自由决定"跳过某一维"？锁死它会损失什么？
- B7 Agent 与固定流水线各自跑一遍，结果差异体现在哪个指标上？
- B8 "工具调用"和"函数调用一次就返回"的本质区别是什么？本项目踩在哪一边？
- B9 这套架构换成纯 prompt 一次性生成，最先崩的是哪一环？
- B10 换成纯规则引擎（不用模型）能到什么程度？哪一步非模型不可？
- B11 面试官问"用了 LangChain/LangGraph 框架，你自己写了什么"——你怎么答？
- B12 你为什么不用"多 Agent 协作"？单 Agent + 预算闸的取舍是什么？
- B13 这套系统里最像"产品判断"而不是"技术选择"的决定是哪个？
- B14 如果让你把项目重新包装成一句话投给面试官，你会突出 RAG、Agent，还是"可审计"？为什么？

## C. 全局架构与数据流（14 题｜基础）

- C1 从浏览器点一次"开始评审"到结果落库，完整走一遍，每步的输入输出是什么？

- C4 同一份论文在系统里一共有几种形态（原始字节、段落、切片、档位…）？分别存在哪？
- C5 哪一个是全系统的"唯一真相源"？有没有同一个事实存了两份？重复了会怎样？
- C6 为什么外部模型调用只允许有一个出口？多开一个出口会付出什么代价？
- C7 一次请求里所有外部调用发生在哪几步？各自失败的表现是什么？
- C8 如果明天拆成两个服务，你沿哪条缝切？切完哪里会变慢、哪里会不一致？
- C9 哪些模块互相之间完全没有依赖？这是刻意设计的还是巧合？
- C10 系统里有两套"评审"概念（预审流水线与记录级问询），它们共享什么、不共享什么？
- C11 为什么问询模块要单独一套表，而不是复用评审那几张表？
- C12 数据从 MySQL 到向量库是单向还是双向？谁负责保持一致？
- C13 一条评审被删除时，向量库里的对应内容会怎样？你靠什么避免它变成幽灵数据？
- C14 画出一次请求的时间线，标出所有可能超过 5 秒的环节。
